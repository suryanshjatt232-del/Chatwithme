# DirectConnect — Connected Visitor & Private Owner Inbox

## How to Run
1. Install Node.js (if not already installed): https://nodejs.org
2. Open a terminal in this folder and run:
   ```bash
   node server.js
   ```
3. Open your browser:
   - **Visitor Website (Chat with Us):** `http://localhost:3000/`
   - **Private Owner Inbox (Only for You):** `http://localhost:3000/owner`

## Default Owner Credentials
- **Username:** `owner`
- **Password:** `123`
- **Recovery PIN:** `1234` (used on "Forgot Username / Password?")

You can change your Owner Username, Password, and Recovery PIN anytime from **Settings** inside the Owner Inbox. All accounts and messages are saved automatically in `data.json`.
